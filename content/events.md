# FIRST BRIEF / DISTRACTIONS

Each event has text and choices. Effects use `gauge +/-number`, separated by commas.

id: icecream
## TEXT

down the street.

effects: energy +8, stress -7, creativity +3
## RESULT

not a breakthrough.
still worth it.

## CHOICE

effects: stress +2
## RESULT
the melody gets smaller.

then starts again.
